## AtCoderでの運用方針

- **コーディング**：CLion（本リポジトリ）で行う。
- **ライブラリ・精進記録**：[Libraries_Solutions_saya38t](https://github.com/saya38t/Libraries_Solutions_saya38t) で管理する。
- **コピー元URL**：原則として上記リポジトリのURLを記載する。必要に応じて、AtCoder上の自分の提出URLも使用する。

本リポジトリは一時的な作業場所ですが、念のため公開しています。

### この運用にする理由
CLionの操作と、十分に整備されていない開発環境での作業に慣れるためです。
